ssignment 7.1 - Responsive Navigation Bar Solution



Key Assignment Implementation Highlights
Flexbox Layout (display: flex): Applied directly to .nav-container to control the header's layout.

Horizontal & Vertical Alignment:

justify-content: space-between places the logo on the left and navigation/action items on the right.

align-items: center perfectly centers all items vertically.

Styling & Transitions: Smooth underline animations on link hover/active states, along with an elevated CTA button design.

Mobile Responsiveness: Uses a @media (max-width: 768px) media query to stack the links vertically into a collapsible menu toggled with a hamburger icon.
